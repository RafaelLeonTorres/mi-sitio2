Programación Orientada a Objetos

La Programación Orientada a Objetos (POO) es un paradigma de programación basado en el concepto de "objetos", que pueden contener datos y código. Los datos se representan como campos, y el código como métodos. Este enfoque organiza el software en objetos que interactúan entre sí, facilitando la modularidad y el mantenimiento del código.

Conceptos Clave

  • Encapsulación: Oculta los detalles internos del objeto y solo expone lo necesario.
  • Abstracción: Permite representar entidades del mundo real a través de clases y objetos.
  • Herencia: Permite a una clase heredar propiedades y métodos de otra.
  • Polimorfismo: Permite a los objetos ser tratados de manera diferente según su tipo.

Ejemplos en C#

Ejemplo de Encapsulación

En el siguiente ejemplo, se muestra cómo encapsular datos utilizando propiedades y métodos.


using System;

public class Person
{
    private string name;
    private int age;

    public string Name
    {
        get { return name; }
        set { name = value; }
    }

    public int Age
    {
        get { return age; }
        set { age = value; }
    }

    public void Introduce()
    {
        Console.WriteLine($"Hola, mi nombre es {name} y tengo {age} años.");
    }
}

class Program
{
    static void Main()
    {
        Person person = new Person();
        person.Name = "Juan";
        person.Age = 30;
        person.Introduce();
    }
}

Ejemplo de Herencia

En este ejemplo, una clase `Employee` hereda de la clase `Person`.


using System;

public class Person
{
    public string Name { get; set; }
    public int Age { get; set; }

    public void Introduce()
    {
        Console.WriteLine($"Hola, mi nombre es {Name} y tengo {Age} años.");
    }
}

public class Employee : Person
{
    public string JobTitle { get; set; }

    public void ShowJobTitle()
    {
        Console.WriteLine($"Mi título de trabajo es {JobTitle}.");
    }
}

class Program
{
    static void Main()
    {
        Employee employee = new Employee();
        employee.Name = "Ana";
        employee.Age = 28;
        employee.JobTitle = "Desarrolladora";
        employee.Introduce();
        employee.ShowJobTitle();
    }
}

Ejemplo de Polimorfismo

El siguiente ejemplo muestra cómo diferentes clases pueden implementar el mismo método de manera diferente.


using System;

public abstract class Animal
{
    public abstract void Speak();
}

public class Dog : Animal
{
    public override void Speak()
    {
        Console.WriteLine("Woof!");
    }
}

public class Cat : Animal
{
    public override void Speak()
    {
        Console.WriteLine("Meow!");
    }
}

class Program
{
    static void Main()
    {
        Animal dog = new Dog();
        Animal cat = new Cat();
        
        dog.Speak();
        cat.Speak();
    }
}

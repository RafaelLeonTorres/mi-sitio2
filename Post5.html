Métodos en una API REST

En este post, exploraremos los métodos básicos en una API REST utilizando ASP.NET Core 8, incluyendo ejemplos para cada método HTTP y cómo implementar paginación.

Métodos HTTP en una API REST

En una API REST, se utilizan diferentes métodos HTTP para realizar operaciones CRUD (Crear, Leer, Actualizar y Eliminar). A continuación, se presentan ejemplos de cada método.

GET

El método GET se utiliza para obtener datos del servidor. A continuación se muestra un ejemplo de un endpoint que devuelve una lista de usuarios.

// C# Example for GET method in ASP.NET Core 8
[ApiController]
[Route("api/[controller]")]
public class UsersController : ControllerBase
{
    private readonly List _users = new List
    {
        new User { Id = 1, Name = "Alice" },
        new User { Id = 2, Name = "Bob" }
    };
    
    [HttpGet]
    public ActionResult> Get()
    {
        return Ok(_users);
    }
}

public class User
{
    public int Id { get; set; }
    public string Name { get; set; }
}

POST

El método POST se utiliza para enviar datos al servidor para crear un nuevo recurso. Aquí hay un ejemplo de un endpoint que agrega un nuevo usuario.

// C# Example for POST method in ASP.NET Core 8
[HttpPost]
public IActionResult Post([FromBody] User user)
{
    _users.Add(user);
    return CreatedAtAction(nameof(Get), new { id = user.Id }, user);
}

PUT

El método PUT se utiliza para actualizar un recurso existente. A continuación se muestra un ejemplo de un endpoint que actualiza un usuario.

// C# Example for PUT method in ASP.NET Core 8
[HttpPut("{id}")]
public IActionResult Put(int id, [FromBody] User user)
{
    var existingUser = _users.FirstOrDefault(u => u.Id == id);
    if (existingUser == null)
    {
        return NotFound();
    }

    existingUser.Name = user.Name;
    return NoContent();
}

DELETE

El método DELETE se utiliza para eliminar un recurso. A continuación se muestra un ejemplo de un endpoint que elimina un usuario.

// C# Example for DELETE method in ASP.NET Core 8
[HttpDelete("{id}")]
public IActionResult Delete(int id)
{
    var user = _users.FirstOrDefault(u => u.Id == id);
    if (user == null)
    {
        return NotFound();
    }

    _users.Remove(user);
    return NoContent();
}

Paginación en la API

Para manejar grandes cantidades de datos, se puede implementar la paginación en los endpoints. A continuación, se muestra un ejemplo de cómo implementar paginación en un endpoint GET.

// C# Example for Pagination in ASP.NET Core 8
[HttpGet]
public ActionResult> Get(int pageNumber = 1, int pageSize = 10)
{
    var pagedUsers = _users.Skip((pageNumber - 1) * pageSize).Take(pageSize);
    return Ok(pagedUsers);
}
